# Изменения

## 1.0.7

* **Глубокий автоподбор параметров byedpi**: вместо перебора готовых стратегий строится своя
  команда — 22 базовые техники (split/disorder/OOB/disoob/fake TLS/tlsrec/mod-http), 6 комбинаций
  с лучшей базой и 4 модификатора (TTL, повторы, OOB-символ, MD5 signature). Каждый вариант
  проверяется на YouTube, Discord и Cloudflare через SOCKS-порт byedpi; результат можно
  применить, скопировать и сохранить в `files/autotune-best.txt`.
* Прогресс, этапы и таблица результатов видны в отдельном экране, автоподбор продолжается в фоне.

## 1.0.6

* Telegram-прокси вынесен в отдельный процесс `:tg`: если нативный рантайм падает, приложение
  не вылетает, а показывает ошибку и отчёт.
* Диагностика аварийного завершения: маркер сессии и сторожевой таймер (30 с) — вместо тихого
  зависания «Запуск…».
* Диалог при первом запуске: объясняет, зачем нужно разрешение «Без ограничений», и сразу
  открывает системную страницу настроек батареи. Та же настройка — в «Ещё → Питание».
* Кнопки: текст в одну строку, по центру, с многоточием вместо переноса — больше не «разъезжается».
* Нижнее меню: «Обновления» → «Релизы», подписи в одну строку.
* Стратегии: названия формируются из аргументов (`12. -o1 -a1 -r-5+se`), а не «Стратегия 1»;
  мусорные и слишком короткие списки из сети больше не заменяют встроенный набор.
* Настройки: у поля GitHub-токена пояснение — для публичного репозитория он не нужен.

## 1.0.5

* Telegram-прокси: исправлена сборка Go-рантайма — ELF-сегменты выровнены на 16 КБ
  (Android 15+ на устройствах с 16K-страницами отказывался загружать `libtgwsproxy.so`).
* Telegram-прокси: подбор маршрута при старте — CF WS/80 → CF WSS/443 → конфигурация
  «как в upstream»; в лог и статус пишется, какой вариант сработал.
* Telegram-прокси обновляет пул CF-доменов из Flowseal раз в сутки (как upstream):
  устаревший встроенный список — частая причина «слушает, но наружу не ходит».
* Токены рантайма приведены к набору upstream (`connection_mode`, `cfproxy_priority`,
  `worker_enabled`, `auto_strategy`), чтобы явная политика маршрутов не отключала CF.
* Telegram: предупреждение «маршрут не подтверждён», кнопки «Подобрать маршрут»,
  «Проверить порт» и «Копировать отчёт» для диагностики.
* Стратегии: тест всех стратегий на живом туннеле (YouTube/Discord/Telegram/Cloudflare),
  таблица результатов, «Выбрать лучшую» и сохранение победителя.

## 1.0.4

* Фирменная иконка из десктопного Zapret Manager: adaptive-иконка, круглая и легаси-версии
  для всех плотностей, монохромная иконка уведомлений (замок).
* Логотип приложения на «Обзоре» и широкий логотип в «О программе».
* `tools/make_icons.py` — пересборка иконок из исходного арта `assets/icon/source-icon.png`.

## 1.0.3

* Состояние движков синхронизируется после перезапуска UI-процесса: сервисы отвечают на запрос
  `ACTION_QUERY`, поэтому «Обзор» больше не показывает «выключено» при работающем туннеле.
* Сторожевой таймер остановки: если сервис не подтвердил остановку за 8 секунд, интерфейс
  возвращается в состояние «выключено» вместо вечного «Остановка…».

## 1.0.1

* Проверка сервисов на «Обзоре»: запросы к YouTube, Discord, Telegram и Cloudflare идут через
  SOCKS5-порт byedpi, то есть тем же путём, что и обычный трафик при включённом обходе.
* Версия списков сайтов считается по коммиту каталога `assets`, а не по HEAD репозитория —
  «обновление доступно» больше не появляется из-за посторонних коммитов.

## 1.0.0 — первая версия

* Единое приложение: обход DPI (`VpnService` + byedpi + hev-socks5-tunnel) и локальный
  MTProto-прокси для Telegram (Go-рантайм TG WS Proxy).
* Стратегии byedpi: встроенный набор + поиск, пользовательские аргументы, применение на лету.
* Telegram: порт, маршруты `cf_proxy_ws` / `direct_ws` / `tcp_fallback`, Fake TLS домен,
  ссылки `tg://`, `t.me`, SOCKS5, автозапуск.
* Обновления: самообновление APK (SHA-256 + подпись + versionCode), стратегии и списки сайтов
  из ByeByeDPI, пул CF-доменов из Flowseal/tg-ws-proxy.
* Настройки: тема, автозапуск, DNS, IPv6, раздельное туннелирование по приложениям,
  GitHub-токен, диагностика, экспорт журнала.
* Плитка быстрых настроек для включения обхода.
* CI: сборка APK, публикация релизов, еженедельное обновление сабмодулей из upstream.
