# Play Protect и «вредоносное приложение»

При установке APK из GitHub Play Protect может показать:

> Вредоносное приложение недоступено
> Zapret Manager … Это приложение может быть опасным.

**Это ложное срабатывание эвристики**, а не признак заражения. Так Play Protect реагирует на
самоподписанные APK вне Google Play, которые:

* создают VPN-сервис (`BIND_VPN_SERVICE`) — ускорение соединения;
* поднимают локальный прокси;
* имеют разрешение `REQUEST_INSTALL_PACKAGES` — самообновление;
* подписаны ключом, которого нет в базе Google.

Приложение не отправляет ваши данные: в нём нет телеметрии, а все сетевые запросы идут только
к GitHub, Cloudflare и Telegram (см. [SECURITY.md](../SECURITY.md)).

## Как установить

1. На экране предупреждения нажмите **«Все равно установить»** (внизу мелким шрифтом).
   На некоторых прошивках ссылка называется «Установить без проверки» / «Подробнее → Установить».
2. Если кнопки нет: **Google Play → профиль → Play Protect → шестерёнка → выключить
   «Сканировать приложения с помощью Play Protect»**, установить APK, затем **включить обратно**.
3. Не отключайте Play Protect навсегда — только на время установки.

## Как проверить, что APK подлинный

Сравните SHA-256 файла со значением из релиза (`*.apk.sha256` на странице Releases).
Подставьте своё имя файла — в релизе их три (`arm64-v8a`, `armeabi-v7a`, `universal`):

```powershell
# Windows
certutil -hashfile ZapretManager-Android-arm64-v8a-vX.apk SHA256
```

```bash
# Linux / macOS
sha256sum ZapretManager-Android-arm64-v8a-vX.apk
```

Дополнительно можно убедиться, что APK собран из этого репозитория: сравните
контрольную сумму с файлом `*.apk.sha256` из релиза — приложение проверяет её же
перед установкой обновления.

## Сообщить Google о ложном срабатывании

В Play Store → профиль → Play Protect → «Отправить отзыв» (или «Помощь») опишите ситуацию:
приложение устанавливается вручную, подписано самостоятельно и не распространяется через Play.
Массовые жалобы иногда снимают эвристический флаг, но гарантий нет.

## Почему бывает не только у нас

Такие же предупреждения получают ByeByeDPI, AdGuard, локальные VPN-клиенты и любые
самоподписанные утилиты, работающие с сетью. Единственный способ гарантированно избежать
предупреждения — публикация в Google Play, что для средств ускорения Интернета неприменимо.
