# Материалы для каталогов (F-Droid, RuStore, сторонние сборки)

В Google Play приложение с DPI-обходом и MTProto-прокси не разместить, но для
F-Droid и сторонних каталогов полезно иметь готовые тексты и понятную сборку.

## Короткое описание (до 80 символов)

Обход блокировок на устройстве: byedpi, Telegram-прокси, диагностика.

## Полное описание

Zapret Manager — менеджер обхода блокировок для Android, работающий локально.

* **Обход DPI** через byedpi и hev-socks5-tunnel: готовые стратегии, свои
  аргументы, автоподбор, проверка на реальных сайтах.
* **Telegram MTProto-прокси** через tg-ws-proxy: ссылка формируется на
  устройстве, секрет не покидает телефон.
* **Профили сетей**: под каждую Wi-Fi-сеть — своя стратегия и режим разделения
  трафика (весь трафик, только список сайтов, только выбранные приложения).
* **Списки сайтов и приложений**: правка, массовая вставка, удаление дублей,
  откат к версии из резервной копии.
* **Диагностика**: проверка портов, маршрута и DNS, отчёт и журнал, которые можно
  сохранить в файл и передать.
* **Без телеметрии**: ни аналитики, ни рекламных SDK; наружу уходят только
  запросы проверки обновлений и те адреса, что вы указали сами.

Приложение не проксирует ваш трафик через чужие серверы: туннель поднимается на
самом устройстве.

## Категория и теги

* Категория: «Интернет» / «Инструменты».
* Теги: обход блокировок, DPI, прокси, Telegram, VPN, приватность.

## Разрешения и зачем они

| Разрешение | Зачем |
| --- | --- |
| `BIND_VPN_SERVICE` / VPN-согласие | локальный туннель byedpi |
| `POST_NOTIFICATIONS` | статус движков и восстановление после остановки |
| `REQUEST_INSTALL_PACKAGES` | установка скачанного APK обновления |
| `ACCESS_NETWORK_STATE`, `ACCESS_WIFI_STATE` | профили сетей и перезапуск при смене Wi-Fi |
| `FOREGROUND_SERVICE*` | работа движков в фоне со статусом в шторке |
| `QUERY_ALL_PACKAGES` | выбор приложений для раздельного туннелирования |

## Что нужно для F-Droid

1. **Сборка из исходников.** Нативный слой — сабмодули
   `app/src/main/cpp/byedpi` и `app/src/main/jni/hev-socks5-tunnel`, Go-рантайм
   Telegram собирается `go build` (см. `README.md`, раздел «Сборка»).
   Для рецепта нужны зафиксированные коммиты сабмодулей и Go-цепочка.
2. **Зависимости.** Только AndroidX и Compose; Google Play Services, Firebase и
   проприетарных SDK нет. `material-icons-extended` — Apache 2.0.
3. **Лицензия.** GPL-3.0 (`LICENSE`), совместима с F-Droid.
4. **Политика конфиденциальности.** `PRIVACY.md` — данных не собираем.
5. **Скриншоты.** `docs/screenshots/` (добавляются по мере обновления интерфейса).
6. **Метаданные.** Значок `app/src/main/res/mipmap-*/ic_launcher*`, версия в
   `version.txt`, код версии в `version-code.txt`, APK — `universal` для каталога.

## Что приложению не нужно

* аккаунт и регистрация;
* доступ к контактам, SMS, камере, микрофону, геолокации;
* реклама и встроенные покупки.
